AI-Powered Mental Wellbeing Companion
A web-based mental wellbeing support application that uses the OpenAI API to provide an interactive chatbot experience. The project was developed as a Final Year Project for the BS Software Engineering programme at the Institute of Management Sciences, Peshawar.
Features
- AI Chatbot: Conversational support powered by OpenAI's GPT-4 API.
- Mood Journaling: Create, review, and delete journal entries to record thoughts and emotions.
- Reminders: Set and manage reminders for wellbeing activities.
- Theme Settings: Switch between light and dark themes.
- User Accounts: Register and log in to access personal features.
- Daily Messages: Display inspirational messages to encourage positive habits.
Note: Gamified challenges and automated emotion recognition were explored during development but were not fully implemented in the final version.

Tech Stack
- Frontend: HTML, CSS, JavaScript, Tailwind CSS
- Backend: Node.js, Express.js
- Database: MongoDB, Mongoose
- AI Integration: OpenAI API (GPT-4)
Project Purpose
The goal of this project is to make everyday mental wellbeing support more accessible through a simple digital companion. It brings together AI-powered conversations and practical tools such as journaling and reminders in one web application.
Important Disclaimer
This application is intended for general wellbeing support and self-reflection. It is not a substitute for professional mental health care, diagnosis, or treatment. If you are experiencing a mental health crisis, contact a qualified professional or local emergency service.
